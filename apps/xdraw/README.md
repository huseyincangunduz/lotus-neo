# XDraw Web

XDraw Web, tarayıcı üzerinden çalışan, hızlı not alma ve serbest çizim odaklı bir web uygulamasıdır. Kurulum gerektirmeden çizim yapmanızı, fikirleri görselleştirmenizi ve çalışmalarınızı XDraw proje dosyası olarak saklamanızı sağlar.

## Öne çıkan özellikler

- Tarayıcıda çalışan web uygulaması deneyimi
- Kalem, metin ve boya kovası araçları
- Katman desteği, aktif katmanda çalışma ve katman görünürlüğü/opaklığı yönetimi
- Basınca duyarlı çizim ve yumuşatılmış çizgi deneyimi
- Yakınlaştırma, uzaklaştırma, kaydırma ve uzaktaki öğelere hızlı gitme kontrolleri
- Izgara ve cetvel benzeri arka plan modları
- Geri al/ileri al geçmişi
- Otomatik kayıt ve proje dosyası olarak içe/dışa aktarma
- PNG, WebP ve JPG formatlarında görsel dışa aktarma
- Web Share API desteklenen tarayıcılarda proje paylaşımı

## Geliştirme durumunda olan özellikler

- Resim yükleme ve çizim alanına görsel ekleme
- Silgi, çizgi ve dikdörtgen araçları
- Kütüphane sistemi ile hazır öğeleri tekrar kullanma
- Öğeleri gruplama, birlikte taşıma ve düzenleme
- Daha gelişmiş seçim, hizalama ve düzenleme araçları

XDraw Web halen geliştirilmeye devam ediyor. Geri bildirimler, özellikle farklı cihaz ve tarayıcılardaki çizim performansı, dosya açma/kaydetme akışı ve dışa aktarma kalitesi için çok değerli.

# XDraw Web

XDraw Web is a browser-based web application focused on fast note-taking and freehand drawing. It lets you draw without installation, visualize ideas, and save your work as an XDraw project file.

## Key features

- Browser-based web application experience
- Pen, text, and fill bucket tools
- Layer support, active-layer editing, and layer visibility/opacity controls
- Pressure-sensitive drawing and a smoothed stroke experience
- Zoom, pan, navigation, and quick-jump controls for distant elements
- Grid and ruler-like background modes
- Undo/redo history
- Autosave and project import/export
- Image export in PNG, WebP, and JPG formats
- Project sharing in browsers that support the Web Share API

## Work in progress

- Image upload and adding visuals to the drawing area
- Eraser, line, and rectangle tools
- A library system for reusing ready-made elements
- Grouping elements so they can be moved and edited together
- More advanced selection, alignment, and editing tools

XDraw Web is still actively being developed. Feedback is especially valuable for drawing performance across devices and browsers, file open/save flows, and export quality.
